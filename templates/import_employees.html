Formato nativo Control iD

O sistema reconhece automaticamente o arquivo com o cabeçalho:

cpf;nome;administrador;matricula;rfid;codigo;senha;barras;digitais

Para o cadastro são utilizados somente cpf e nome. Os demais campos, inclusive biometria/digitais e senha, não são armazenados.

O CPF/identificador é convertido automaticamente para o padrão de 12 dígitos usado pelo AFD do relógio. Ex.: 3526693064 → 003526693064.

Outros formatos continuam aceitos

  • Nome do colaborador
  • CPF/ID;Nome do colaborador
  • Nome do colaborador;CPF/ID
  • Também aceita TAB, vírgula e | como separadores.

Como o sistema trata duplicados

Quando houver identificador AFD/CPF/ID, ele será usado como chave principal. Se o colaborador já existir, o nome será atualizado e o cadastro será reativado.

Quando o arquivo tiver apenas nomes, o sistema procura um nome igual (ignorando maiúsculas/minúsculas). Se encontrar, reativa o cadastro; caso contrário, cria um novo colaborador.
